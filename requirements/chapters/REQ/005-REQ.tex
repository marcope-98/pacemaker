% ===================================================================
\section{REQ-005 -- \texttt{IncaExperimentViewProxy}}
% ===================================================================
\label{sec:incaexperimentviewproxy}

\reqfield{Title:} Proxy for the INCA experiment-view COM object \status{implemented}

\medskip
\reqfield{Intent:}
The user needs to programmatically open a measurement view for a specific calibration
data item inside INCA, so that data can be observed in the INCA GUI during an automated
experiment run.

\medskip
\reqfield{Acceptance criteria:}
\reqdef{\textbf{AC-005-4}}{The class shall respect all the requirements of \texttt{COMProxy}.}

\medskip
\reqfield{Testing:}
See test document, section \textit{TC-005}.
